p5.js · Interactive sketch

Interactive Face

Concept
This is my basic face made with couple of shapes and functions. By connecting canvas elements with mouse position and clicks, the artwork feel playful and with a bit of chaos
What I did
In this sketch I divided it into 3 parts, the face, the eyes and the mouth and tears using basic geometric shapes. I also integrated the pupils with interactive mouse tracking (mouseX, mouseY) with the constrain() function and the random() function to give it more lively effect. And finally, I added the mouseIsPressed() function to change all of the face feature's color give it a more chaotic feel.
What I learned
This exercise was a good practice to get familiar with the basic shapes and functions for me. It was quick and simple some parts I found it challenging to implement the interactive elements

p5.js · Interactive sketch

Cat or Dog?

Concept
This is the second exercise where I explored more advanced p5.js functions. Using the Interactive Face project as the template, I experimented with different built-in functions and techniques. the most interesting part was toggling between cat and dog completely using keys
What I did
In this sketch, I focused on enhancing the interactivity and visual appeal of the artwork. I programmed the toggling using the variable (isCat) to toggle between the two states with key presses ('C or c' for cat, 'D or d' for dog). I used one of the examples templates to tweak them for the background. Using Perlin noise (noise()) to generate verticle color stripes, alongside with an animated text drop ("MEOW" or "WOOF") that resets and scales up using loadFont() whenever the character state changes
What I learned
Getting familar with effect like noise and frameCount is challenging but it was fun once I understand them. Despite this project can be way more overwhelming without the examples, I was able to understand the logic behind the code and use it in my own way.

p5.js · Drawing tool

Digital Drawing Studio

Concept
For this project, I want to approach it in a directive way, what do I usually use for painting, what function do I need and how to make the drawing experience effective and smooth
What I did
To create a more versatile and user-friendly drawing experience, I developed a collection of brushes like particle airbrushes and multi strand hairbrush. I also added the native DOM components like HSB color sliders and a live color preview block that directly update stroke properties. To ensure seamless control, I also implemented an undo and and redo history system just like in the standard drawing system (Ctrl+Z/Ctrl+Shift+Z). And finally for a nice touch, I added linear interpolation (lerp()) to smooth cursor movement while drawing and a stickykey hold to allow continious adjustment to brush sizes ([and])
What I learned
Through building this small program, I gained a much more understanding of digital drawing management using stack manipulation like (push() and pop()) and how to implement a more complex system with multiple functions. I also learned how to use the lerp() function to create smooth transitions and movements.
